# flexion-browser
Flextion Browser
Flextion Browser is a fast and lightweight web browser built for comfortable, clean, and personalized browsing.


Key Features
Built-in AdBlock — blocks ads, trackers, and pop-ups out of the box for a cleaner web experience.
22 themes with live wallpapers — animated backgrounds that make every browsing session feel unique.
A wide collection of additional themes — from minimal and clean to bold and colorful.
High performance — an optimized engine for fast page loading and smooth browsing.
